# BCBM v55.67 — Commission Target Exemption

- Commission-basis salary is calculated from confirmed personal sales and saved per-product commission rates.
- Admin Edit Salary hides and disables the monthly carton target field while Commission basis is selected; the stored operational target is preserved.
- Fixed-salary fields and target-based incentive inputs remain available only for Fixed salary.
- No database migration is intended.

Validation: JavaScript syntax and ZIP integrity checks only. Live Supabase/browser behavior has not been tested.
