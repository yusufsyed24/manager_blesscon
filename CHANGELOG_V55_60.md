# v55.60 — Admin uploads for Manager profiles

- Added an Admin-only document uploader inside Admin → Users & Access → Manager → Profile.
- Supports any file format with a 25 MB per-file limit; files are stored in the private `employee-private` bucket under the manager's account folder.
- Added document categories for identity, education, appointment, contract, employment, salary/bank, tax/compliance, training, performance, policy, medical/leave, and other documents.
- Added `supabase/manager_admin_document_upload_v55_60.sql` to expand the document type/size constraints and permit Admin uploads through row-level security.
- Kept documents private; access is through signed links generated by the app.
